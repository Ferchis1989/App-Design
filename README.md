## ¿Qué es Markdown?
Markdown es un lenguaje de marcado ligero que permite dar formato a texto de manera simple y rápida.

---

## Opciones de formato de Markdown
Markdown ofrece varias opciones para dar formato al texto. Aquí hay algunos ejemplos:
- **Encabezados**: Usa `#` para encabezados (del nivel 1 al 6).  
  Ejemplo: `# Encabezado`  
- **Negrita**: Usa `**texto**` o `__texto__`.  
- **Cursiva**: Usa `*texto*` o `_texto_`.  
- **Listas**:
  - Listas ordenadas: Usa números (`1.`, `2.`).  
  - Listas desordenadas: Usa guiones (`-`) o asteriscos (`*`).  
- **Enlaces**: `[texto](URL)`.  
- **Imágenes**: `![Texto alternativo](URL)`.  
- **Bloques de código**:  
  - Línea de código: Usa backticks (`\``).  
  - Bloque de código: Usa triple backticks (\```).

## Comandos básicos de Git

### 1. Verificar el estado del repositorio local
git status
### 2. Agregar archivos individuales o glabales
git add <nombre-del-archivo>
git add .
### 3. Agregar comentarios al commit
git commit -m "El mesaje"
### 4. Subir los cambios al repositorio
git push origin <nombre-de-la-rama>
### 5. Crear, navegar y borrar ramas
git branch <nombre-de-la-rama>
git checkout <nombre-de-la-rama>
git branch -d <nombre-de-la-rama>
### 6. Retroceder a un commit especifico
git reset <commit-hash>
git reset --hard <commit-hash>
